## 2. Official Logo

### 2.1 Logo Description

**Visual Elements**:
- Eye-shaped frame with blue-to-purple gradient
- Central circle containing heartbeat/pulse waveform
- White accent elements for contrast
- Geometric, modern design language

**Color Composition**:
- Primary Gradient: Cyan Blue (#0EA5E9) → Royal Blue (#2563EB) → Deep Purple (#7C3AED)
- Accent: Pure White (#FFFFFF)
- Background: Transparent

### 2.2 Logo Usage Rules

**✅ ALLOWED**:
- Proportional scaling (maintain aspect ratio)
- Different output sizes (favicon, app icon, header)
- Transparent background usage
- Monochrome conversion (for specific contexts)

**❌ NOT ALLOWED**:
- Redesign or modification
- Color changes
- Gradient alterations
- Proportion changes
- Redrawing or tracing
- Cropping or clipping
- Shadow or effects addition
- Visual effect changes

### 2.3 Logo Specifications

| Specification | Value |
|---------------|-------|
| **Format** | PNG (primary), SVG (reserved) |
| **Aspect Ratio** | 1:1 (square) |
| **Minimum Size** | 32px × 32px |
| **Recommended Size** | 40px × 40px (header), 64px × 64px (hero) |
| **Safe Margin** | 8px clear space around logo |
| **Background** | Transparent (PNG) |

### 2.4 Logo Outputs

| Output | Size | Usage |
|--------|------|-------|
| **favicon.ico** | 32×32, 64×64 | Browser tab |
| **apple-touch-icon.png** | 180×180 | iOS home screen |
| **icon-192.png** | 192×192 | Android app icon |
| **icon-512.png** | 512×512 | PWA splash screen |
| **og-image.png** | 1200×630 | Social media preview |

## 6. Gradient Specifications

### 6.1 Primary Gradient

**Direction**: 135° (top-left to bottom-right)  
**Colors**: Cyan (#0EA5E9) → Blue (#2563EB) → Purple (#7C3AED)  
**Usage**: Buttons, hero sections, emphasis elements

**CSS**:
```css
background: linear-gradient(135deg, #0EA5E9 0%, #2563EB 50%, #7C3AED 100%);
```

### 6.2 Subtle Gradient

**Direction**: 180° (top to bottom)  
**Colors**: #1E293B → #0F172A  
**Usage**: Backgrounds, subtle depth

**CSS**:
```css
background: linear-gradient(180deg, #1E293B 0%, #0F172A 100%);
```

### 6.3 Accent Gradient

**Direction**: 45°  
**Colors**: #0EA5E9 → #7C3AED  
**Usage**: Hover states, highlights

**CSS**:
```css
background: linear-gradient(45deg, #0EA5E9 0%, #7C3AED 100%);
```

## 9. Loading Animation Specifications

### 9.1 Logo Loading State

**Animation Type**: Breathing effect (opacity + subtle scale)  
**Duration**: 1 second loop  
**Easing**: ease-in-out

**CSS**:
```css
@keyframes pulse-breathing {
  0%, 100% { opacity: 0.6; transform: scale(1); }
  50% { opacity: 1; transform: scale(1.05); }
}

.pulse-loading {
  animation: pulse-breathing 1s ease-in-out infinite;
}
```

### 9.2 Alternative: Gradient Shimmer

**Animation Type**: Gradient shift  
**Duration**: 2 seconds loop  
**Usage**: Card loading states

**CSS**:
```css
@keyframes shimmer {
  0% { background-position: -1000px 0; }
  100% { background-position: 1000px 0; }
}

.loading-card {
  background: linear-gradient(90deg, #1E293B 25%, #334155 50%, #1E293B 75%);
  background-size: 1000px 100%;
  animation: shimmer 2s infinite;
}
```

## 15. Accessibility

### 15.1 Color Contrast

- **Text on Background**: Minimum WCAG AA (4.5:1)
- **Interactive Elements**: Minimum WCAG AA (3:1)
- **Focus Indicators**: Visible 2px outline, 2px offset

### 15.2 Motion

- **Prefers Reduced Motion**: Disable animations
- **Focus Management**: Logical tab order
- **Keyboard Navigation**: All interactive elements accessible

### 15.3 Semantic HTML

- Use `<button>` for buttons, not `<div>`
- Use `<nav>` for navigation
- Use `<footer>` for footer
- Use `<header>` for header
- Use `<main>` for main content

## 16. Implementation Guidelines

### 16.1 CSS Variables

All colors, spacing, and typography should use CSS variables defined in `client/src/index.css`.

**Example**:
```css
:root {
  --color-primary: #2563EB;
  --color-accent: #0EA5E9;
  --color-text: #F1F5F9;
  --spacing-md: 16px;
  --font-size-base: 1rem;
}
```

### 16.2 Component Consistency

- All buttons use the same styling system
- All cards follow the same specifications
- All inputs have consistent focus states
- All animations use the same timing

### 16.3 Brand Asset Management

**Location**: `client/public/brand/`

**Structure**:
```
brand/
  logo/
    pulse-logo.png
    favicon.ico
    apple-touch-icon.png
    icon-192.png
    icon-512.png
  og/
    og-image.png
  manifest/
    site.webmanifest
```

### 16.4 Configuration

All brand information is centralized in `client/src/config/brand.ts`. No hardcoding of brand names, logos, or links.
